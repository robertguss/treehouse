# Game designs

One file per game, written before the code: `docs/games/<id>.md`.

1. **The idea** in two sentences.
2. **Who plays**: which family members, on which devices, together or alone.
3. **Controls** for touch and for keyboard/mouse.
4. **Roles**: what each family member's role can do (if it matters).
5. **What done looks like**: the moments that must work, as test ideas.
6. **Not now**: what is deliberately out of scope.
